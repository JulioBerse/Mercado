# 🛒 Mercado - Sistema PDV & Dashboard Analítico

Uma solução web completa desenvolvida para a gestão de mini mercados e comércios locais. O sistema oferece módulos integrados de **Frente de Caixa (PDV)**, **Gerenciamento de Estoque** e **Dashboard Analítico** com controle de perfis de acesso.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Framework Web:** Flask
* **Banco de Dados:** PostgreSQL (Hospedado no Cloud Server Neon)
* **ORM / Drivers:** psycopg2 / SQLAlchemy
* **Hospedagem / Deploy:** Render / GitHub Pages

---

## 📌 Funcionalidades Principais

* **Frente de Caixa (PDV):** Registro ágil de vendas, baixa automática de itens no estoque e fechamento diário.
* **Gestão de Estoque:** Entrada e atualização de produtos, suporte a avisos de estoque baixo e controle simples para fácil operação diária.
* **Dashboard Analítico:** Visualização de indicadores financeiros, histórico de movimentações e acompanhamento de fluxo de caixa.
* **Controle de Acesso:** Perfis com níveis de permissão específicos para operadores de caixa e administradores.
