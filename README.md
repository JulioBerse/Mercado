# Mercado
Sistema PDV (Frente de Caixa) e Dashboard analítico web desenvolvidos em Python (Flask) e PostgreSQL, com controle de perfil de acesso, atualização de estoque e arquitetura pronta para nuvem . Feito para um mini mercado de bairro , por isso a ausência de logotipo e marcas no pdv e na entrada/saída de estoque .
